# v2: preprocess → single-call agent → web

```
case.md ─▶ preprocess/preprocess.py ─▶ deskagent_v1_1 (1 Claude call, structured output) ─▶ api_v2 ─▶ web_v2
```

| Piece | What it is |
|---|---|
| `deskagent_v1_1/` | One call per case. System prompt is `preprocess/delivery_desk_system_prompt.md`, read at run time. Output is its section-10 JSON via structured outputs (`models.py`). `checks.py` compares the classifier hints with the agent's answer. |
| `api_v2/` | Stateless FastAPI: `POST /api/v2/run`, `GET /api/v2/samples[/name]`, `GET /api/v2/spec`. No DB, no login. `V2_API_TOKEN` (optional) adds a bearer check. Cases are read from `cases/` (copied from `test/cases`; `V2_CASES_DIR` overrides). Also serves the built `web_v2/dist`, so Node is not needed to use the UI. |
| `web_v2/` | Copy of `web/` without Supabase. **Cases** (all cases in a left panel, tickets in order, **Run agent** appends the agent's ticket) and **Investigate** (classifier tiles, agent confidence, agreement checks). Runs can be downloaded and re-opened. |

Needs `ANTHROPIC_API_KEY` and `OPENROUTER_API_KEY` in `.env`. Model: `V11_MODEL` (default `claude-opus-5-5`, falls back via `DESK_MODELS`).

```bash
pip install -r requirements.txt
source .venv/bin/activate
uvicorn api_v2.app:app --port 8100            # UI + API at http://localhost:8100
# frontend dev only (needs Node): cd web_v2 && npm install && npm run dev   → http://localhost:3001

python -m deskagent_v1_1 ../test/cases/delivery_001.md      # CLI: prints the run JSON
pytest tests/test_v11.py                                    # offline tests
```

"Agent confidence" is the model's self-reported level (high/medium/low). The API exposes no token probabilities, so there is no percentage; read it next to the agreement checks.
